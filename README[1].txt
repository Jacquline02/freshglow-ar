3. script.js - interactive buttons

HOW TO TEST:
1. Keep all files in the same folder.
2. Double-click index.html.
3. The FreshGlow webpage opens in your browser.
4. Test the navigation, rotating video, ingredient/benefit/how-to-use buttons.

FOR QR CODE:
The QR code should contain the FINAL ONLINE URL of index.html after you host this folder on a web-hosting service. Do not make the QR code from the local file path.
